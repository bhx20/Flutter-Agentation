# Flutter Agentation Example

This example demonstrates how to integrate `flutter_agentation` into a Flutter application.

## Quickstart

1. Run this example on your preferred platform:

```bash
flutter run
```

2. Notice the floating toolbar at the bottom of the screen.

3. Tap the **Target / Inspect** icon (or press `Ctrl+Shift+A` / `Cmd+Shift+A`) and click on any widget on the screen (such as the Card, Button, or Text).

4. Add your visual feedback or annotation note.

5. To connect your AI coding agent (Cursor, Claude Desktop, Windsurf, VS Code, or Antigravity), run:

```bash
dart run flutter_agentation:setupmcp
```
